# Historical archive

This directory contains frozen checkpoint reports and one-off recovery
material. They are retained for provenance and regression research, but their
counts are superseded by the generated status under [`../status/`](../status/).

- `checkpoints/` — numbered Progress and HUNT reports.
- `legacy/` — former live status files and the chronological research log.
- `root-notes/` — small package notes formerly stored in the repository root.
- `recovered-packs/` — recovered package mappings and hashes.

Archived documents may describe paths and commands exactly as they existed at
their checkpoint. Do not use them as the current setup guide.
