The PGEN delta is small and explicit: `amigaModInit` copies the 16-byte RPC
banner as one EE `u128`, while `amigaModLoad` relies on the caller's already
initialized IOP heap instead of calling `SifInitIopHeap` again.

The DSP1 functions preserve the original source's arithmetic, including the
historical `Atan` condition `(x >= 1) || (x <= 1)`. They require the ordinary
64-bit double ABI rather than the `-fshort-double` profile used by many other
Snes9x translation units.

## PS2 `Settings` layout

The remaining near-matches exposed one extra byte in the PS2 port's
`SSettings` layout immediately before the per-game fix flags. This shifts the
game-fix bytes by one and, through natural alignment, `DisplayColor` by two.
Applying that single layout fact to the pinned official Snes9x 1.41-1 source
proves these six complete symbols:

- `ForceInterleave1OverrideSnes9x`
- `S9xDeinterleaveMode2`
- `CMemory::HiROMMap`
- `CMemory::TalesROMMap`
- `CMemory::KartContents`
- `S9xUpdateJoypads`

The evidence runner names the unknown semantic field `PS2PortLayoutByte`; the
name is intentionally neutral because only its size and position are proven.

## Reproduce

Place the private original at `original/SNES_EMU.ELF`, then run:

```sh
make reference
make hunt1041-v51-evidence EE_BUILD_JOBS=8
python3 tools/research/hunt1041_v51_closure.py --apply
make check
```

Machine-readable proof is in
[`hunt1041-v51-validated-16.tsv`](../analysis/matching/hunt1041-v51-validated-16.tsv).
The original ELF and generated `build/` objects remain ignored and must not be
committed or redistributed.

This is a function-level matching checkpoint, not yet a claim that the final
historical link or packed replacement ELF has been reproduced.
