# HUNT1041 V49 — 945-match formal-ELF closure

V49 promotes **20** strict matches, moving the audited checkpoint from
**925/1041 (88.86%)** to **945/1041 (90.78%)**. There are **96** entries left.

| Evidence class | New matches | Proof |
|---|---:|---|
| Official Snes9x / PGEN / PS2LIB objects | 17 | full historical-symbol context against the original ELF |
| Corrected recovered SNES Station C | 3 | exact next-address spans |

Unlike V48, this round deliberately has no committed-listing fallback. Every
row requires the unpacked original with SHA-256
`739e058834564ba81c2d8fc61fd9977502e9714c7eaafdd3a4ce3ec546fad71b`.
This is necessary because multiple audited entries begin inside a historical
compiler symbol or end before the next manifest address. The runner compares
both the promoted slice and the entire containing symbol, normalizing only
known MIPS relocation-controlled bits.

## Corrected recovered identities

The formal bytes disproved three older behavioral labels:

| Address | Correct source identity | Exact size |
|---|---|---:|
| `0x00101e8c` | flush GS pipe, acknowledge/wait for VSINT, swap buffers | 100 |
| `0x00104e58` | per-ROM/APU cleanup followed by the noreturn exit wrapper | 36 |
| `0x00106bcc` | case-insensitive `.srm` extension test | 60 |

The GS helper includes one explicit EE `nop` representing the original GS CSR
read delay. The other two entries had previously been mistaken for multitap
and SjPCM RPC functions; their canonical recovered sources and manifest names
are corrected in this round.

## Historical symbol ownership

The official Snes9x 1.41-1 object profile proves compiler-owned ranges for
`OpD6M0`, two `REGISTER_2122` instances, six SuperFX helpers,
`S9xGraphicsInit`, `S9xSetupOBJ`, `DrawBackgroundMode5`, and `Apu9F`.
`S9xSetupOBJ` and `DrawBackgroundMode5` each cover two adjacent manifest rows.
The SuperFX rows are terminal tails except for `0x0013fc10`, whose four-word
closed slice is explicitly checked as two ordinary instructions followed by
`jr $ra` and its delay slot.

The final manifest entry at `0x001b0790` is the complete historical
`gsDriver::getTexSizeFromInt` symbol from PGEN's prebuilt `libgs.a`. Its
terminal return supplies the final-boundary proof even though no later manifest
address exists.

The startup row at `0x001000e0..0x00100114` is an exact 52-byte partition of
the 15 April 2004 PS2LIB startup object's `_exit` (44 bytes) and `_root`
(8 bytes). Both symbols and their adjacency are independently checked.

## Reproduce

Place the original packed ELF at `original/SNES_EMU.ELF`, then run:

```sh
make reference
make hunt1041-v49-evidence EE_BUILD_JOBS=8
python3 tools/research/hunt1041_v49_closure.py --apply
make check
```

The original ELF and generated build directory are ignored and must not be
committed or redistributed. Machine-readable proof is in
[`hunt1041-v49-validated-20.tsv`](../analysis/matching/hunt1041-v49-validated-20.tsv).

This remains a function-level matching checkpoint, not a claim that the final
historical link or packed replacement ELF has been reproduced.
